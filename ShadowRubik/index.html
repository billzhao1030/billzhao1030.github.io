How it works

Look, plan, act, check — and always come home

Every atomic move is turn a layer + return to the standard grip. With that one contract, moves compose like building blocks.

↺

One standard grip

Left thumb and middle finger pinch the F and B centres; the right hand owns the R layer. Every move starts and ends here, so the policies never see each other's leftovers.

⌁

Learned with RL

Each move is a reference path plus a policy that learns per-motor corrections (MuJoCo Warp + PPO). Its way back is trained on the move's real end states.

✓

Checked, not hoped

At every stage the executor reads all 54 stickers from the simulated cubies and compares them with the logical cube, and measures how far the hands are from the grip.

The agent

The agent can be a planner — or a language model

Swap the planner for an Opus session. It sees the cube as the hands hold it, answers each CFOP stage once — what it sees, a rotation or a U turn, then the algorithm it knows — and the hands execute it. No cube tool, no search.

The hands executing Opus's own solution, its thought for each stage on top. Solved.
